# November 2026

## 2.60.4-local.2 — Reliable ComfyUI readiness during batches

Replaces the GPU-stat readiness check and two-second timeout with a lightweight queue check,
ten-second response allowance, and shared concurrent probes. Busy workers remain ready.
Verified workers skip HTTP checks during admitted renders, while still checking their TCP
listener; a bounded recent-success fallback covers transient stalls from other clients.
Listening servers that fail readiness now report a wait/retry diagnostic instead of telling
users to start duplicates. Adds ten regression tests and safe staging of desktop updates while
the previous executable is running; close and relaunch with `launch-desktop.bat` to apply.

## 2.60.4-local.1 — Optional native local inference

Adds keyless NInfer Qwen text features and an image pool dividing batches between RTX 3090
and 4090. Jake's Krea 2 API workflow is selectable alongside standard checkpoints. Settings
detect and launch local services; native exit stops only app-owned descendants. Adds image
provenance, partial-batch error reporting, and portable Windows build/launcher.
See [local inference](../systems/local-inference.md).
