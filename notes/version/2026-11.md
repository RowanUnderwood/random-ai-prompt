# November 2026

## 2.60.4-local.15 — Anime characters get their own block

`{#person}` is now always a described adult, and `{#entity}`, `{#living-entity}` and `{#entity-name}` no
longer name anime characters. The new `{#anime-character}` does, in everyday clothes (new
`{clothes-everyday}` list) with SFW expressions. Swimsuit and bunny-suit variants leave the character names,
and `{#prompt/d}` no longer mixes named characters with adult tags.

## 2.60.4-local.14 — Old block paths work again

Full paths to blocks that moved in .12 and .13 (`{#subject/person}`, `{#style/sticker}`, `{#fragment/neon}` and
others) produced nothing. They now find the block in its new folder.

## 2.60.4-local.13 — Pure styles, styled subjects and Krea categories

`{#style}` now holds 18 pure looks: 12 new ones and six Krea categories (a third of picks). The 19 looks that
bring their own subject move to `{#styled-subject}` with far more variation; short names still work.
Adds the `medium/` lists. Fixes `{#entity}`, which only ever named its subject. Full paths such as
`{#style/sticker}` change to `{#styled-subject/sticker}`.

## 2.60.4-local.12 — People, new subjects and no more empty blocks

Adds `{#people}` (occupations, historical, fantasy and sci-fi roles, pairs, groups, bands) and object, food,
machine and animal-scene subjects; `{#person}` describes an adult instead of saying "person". Weather,
water, wildlife, expressive, fx and the mood fragments always give something; scenes keep their
former weather, water and wildlife rates. Building pieces leave the random groups. `{#prompt}` skips
artists while they are off. Anime characters draw SFW clothes only. Adds `{#camera}`.

## 2.60.4-local.11 — Larger and cleaner lists

Expands construct, view, weather, time, mood and expression; adds shot, lens, calendar, water,
animal-behavior, and the `people/` and `thing/` folders. `{#action}` grows from 72 to 180 activities.
Weekdays and months move to `{calendar}`; suggestive expressions move behind the NSFW switch.

## 2.60.4-local.10 — Restore default fix, list hygiene

Fixes Manage's Restore default, which deleted files instead of restoring them. It now uses this fork's
`main` and never deletes. List files no longer yield blank entries. Removes 861 duplicate list lines.
Adds `scripts/variety-report.mjs` and content-quality tests. Pinned seeds give different results.

## 2.60.4-local.9 — Krea sizing, editable auto-fix prompt, shuffled decks

Krea sizes are set with a short edge and one of 14 aspect ratios, plus an orientation swap and a pixel
readout. Prompt settings gains an editable auto-fix system prompt with reset (positive prompts only) and
**Draw from shuffled decks**: no list entry, block or unweighted choice repeats until all have been
used, across batches, until the app restarts. Removes a checkbox that did nothing. Composer tools
now wrap instead of squashing the action buttons. Adds CLI `--shuffle-deck` and `--rewrite-system`.

## Documentation — Direct pushes to the fork's main (2026-11-25)

Removes the pull-request-only rule for this fork's `main` at the owner's request. An explicit go-ahead,
a green local gate and fast-forward-only pushes still apply; upstream's protection is unchanged.

## 2.60.4-local.8 — Auto-add FX checkbox

Adds **Auto-add FX** to Prompt settings (web, desktop and mobile). A hint appears when the active
wrapper already contains `{#fx}`, because effects then appear either way. Fixes auto-added
effects/artists leaking into negative prompts, the rotating suggestion, and mobile examples.

## 2.60.4-local.7 — SeedVR2 upscaling on the RTX 4090

Adds SeedVR2 to Single view's Resize menu and an Upscale action to Gallery multi-select. Jobs share
the GPU queue with renders: Single-view upscales run next on the 4090 without interrupting anything,
and the 3090 keeps rendering. Shows queue position and progress, supports cancelling, survives a page
reload, and links each result to its source. The 4000px target and seed are adjustable. Output is
pixel-identical to the supplied workflow. Dialog messages now keep their line breaks.

## Fix — ComfyUI upscaler (ships in 2.60.4-local.7)

Makes the existing "AI Upscale · ComfyUI" entry usable: no API key is required, simultaneous jobs
keep separate source images, ComfyUI errors are reported at once, and waiting behind other work in
ComfyUI's queue no longer counts as a timeout. Adds five regression tests.

## 2.60.4-local.6 — Krea 2 identities, styles and SD visibility

Adds Subject `{#krea2-actors}` with 1,010 identity-only source names, a separate 53-band list,
and Style `{#krea2-style-library}` with 288 intact descriptors. Deduplicates source identities,
removes portrait framing, and retains attribution/source accounting. The blocks participate in
normal category groups. Krea-specific additions hide for SD selections across web/mobile catalogs,
completions, vocabulary choices and shared-engine random/group/wildcard resolution. Krea model
selection is independent of SD-compatible prompt syntax; model switching restores the content.

## 2.60.4-local.5 — Curated human action fragment

Adds `{#action}`: one human activity with matching pose/props, drawn from 72 curated Kinetics-700
labels in six reusable family lists. Preserves the existing `{action}` list. Includes downloaded
label provenance, CC BY 4.0 attribution, offline regeneration and real Node/browser/Metro checks.
The fragment composes explicitly with human subjects; it does not infer subject compatibility.

## 2.60.4-local.4 — Single-view render editor and image-only viewing

Adds Render another beside Resize, with optional positive/negative prompt editing before queueing
one linked image using the saved recipe and a fresh seed. Clicking the main image opens an uncropped,
aspect-preserving image-only viewport; arrows navigate and click/Escape restores Single. Fixes
gallery shortcuts intercepting text-editor/modal input. Includes regression tests and a safely
staged native desktop update.

## 2.60.4-local.3 — Live ComfyUI model selection

Adds workflow-specific diffusion-model and checkpoint dropdowns populated from enabled ComfyUI
instances. Models common to reachable workers are selectable; Refresh models reloads their lists.
Saved selections persist, availability problems are reported, and chosen filenames reach the
workflow and metadata without silently substituting another model. Includes UI/catalog/generation
tests and a staged native desktop update.

## 2.60.4-local.2 — Reliable ComfyUI readiness during batches

Replaces the GPU-stat readiness check and two-second timeout with a lightweight queue check,
ten-second response allowance, and shared concurrent probes. Busy workers remain ready.
Verified workers skip HTTP checks during admitted renders, while still checking their TCP
listener; a bounded recent-success fallback covers transient stalls from other clients.
Listening servers that fail readiness now report a wait/retry diagnostic instead of telling
users to start duplicates. Adds ten regression tests and safe staging of desktop updates while
the previous executable is running; close and relaunch with `launch-desktop.bat` to apply.

## 2.60.4-local.1 — Optional native local inference

Adds keyless NInfer Qwen text features and an image pool dividing batches between RTX 3090
and 4090. Jake's Krea 2 API workflow is selectable alongside standard checkpoints. Settings
detect and launch local services; native exit stops only app-owned descendants. Adds image
provenance, partial-batch error reporting, and portable Windows build/launcher.
See [local inference](../systems/local-inference.md).
