## Random toggle and Krea-aware suggestions

The owner asked whether the prompt box's "Random — drop a suggestion in" button uses the Krea additions,
and to make it an on/off toggle that rolls a new suggestion per Generate and per prompt in a batch.

Findings: it rolled `{#random-words}`, which reached Krea only through the `{keyword}` wildcard (1.7% of
77,801 lines, about 1 suggestion in 10) and never used the Krea blocks. SD hiding worked. A batch from an
empty box repeated one pre-rolled suggestion.

Owner decisions: a structured `{#suggestion}` block; append to typed text; web, mobile and CLI. While
sampling, a suggestion paired `{#anime-character}` (via `{#subject}`) with wildcard keywords, which with
NSFW on could be adult vocabulary, so the block uses `{keyword-sfw}`. Krea hit rate is now about 30% with
the Krea workflow and 0% with an SD checkpoint. See [the plan](../../plans/random-suggestion-toggle.md).

The content-quality reference check now accepts `{keyword-sfw}`/`{keyword-nsfw}`, which the engine
already supported. The compiled `en-XA` pseudo-locale was stale from earlier features and was
regenerated. The CLI could not be run live: `targets/cli/node_modules` is missing and `npm ci` refuses
its out-of-sync lockfile (predates this); the flag is covered by unit tests instead.

Verification: full `npm test` green, 1,189 tests (573 Node, 491 web, 125 mobile); web production
build passes. Live in the dev server (system Edge via Playwright, since Playwright's own browser is not
downloaded): with "a red fox" and Prompts 4, Random off gave four prompts from the same text; on gave
four different suggestions, and a second click four new ones; the box text stayed unchanged and the
toggle shows the "on" style. Krea styles and a Krea band appeared.

Also fixed a pre-existing race: `contentQuality.test.js` failed 3 of 4 runs with ENOENT on
`zz-manage-test` (see fix-patterns). Noticed, not changed: alternation output such as
`Graffiti|Underground comix` appears in generated text with default settings (keyword alternating),
including between two long Krea style descriptors. That syntax means nothing to Krea.
