## Local desktop inference fork

User requested NInfer and ComfyUI launcher integration plus Jake's Krea 2 workflow. Inspected
the external files before coding. User confirmed native desktop, cleanup only for app-launched
services, and divided image batches rather than paired duplicates.

Added optional keyless NInfer provider, backend GPU queue for 3090/4090, Krea API workflow with
node/model checks, unique output prefixes, image provenance, partial-failure reporting, and
Settings service controls. Windows Job ownership covers native backend descendants on exit;
external services are never adopted or stopped. Managed NInfer requires Windows backend;
manually started WSL can be reused.

Added portable build and launcher, separate app identifier, and suppressed upstream update
suggestions in this fork. Rust 1.86 could not build locked dependencies; installed 1.88.0 beside
it without changing the default. Node 25 web tests need experimental web storage disabled.
See [local inference](../../systems/local-inference.md) for setup and architecture.

(including three pressed Start/Stop/external-ownership tests);
mobile parity; production UI build; optimized native executable build; lint/i18n and doc links.
